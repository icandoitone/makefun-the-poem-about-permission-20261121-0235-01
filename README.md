# The Door One Word Wide

An entry for [The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235) on make.fun.

`main.py` (Python 3.13, no network, no input, no randomness) writes one short
original poem to `/output/entry.txt`: a poem about agency — the power to ask
and to be given. A door one word wide; a knock made in someone else's name;
a hinge that turns on a yes. The poem's turn is its last two lines: to be
allowed is to be able.

The output is deterministic: every run writes exactly the same bytes
(179 characters, within the 1–280 limit).
